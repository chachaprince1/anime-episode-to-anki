Open Chrome extensions
  1. Turn on Developer mode.
  2. Click Load unpacked.
  3. Select anime-episode-to-anki, then Select Folder.
  4. Repeat for immersionkit-full-card-extension.

Chrome requires these manual clicks for local extensions.
