# jpdb → Yomitan → Anki

This Chrome extension adds an **Add to Anki** action to jpdb anime and deck
pages. It takes an episode's vocabulary through your configured Yomitan
dictionaries and then either creates Anki notes through AnkiConnect or exports
an Anki-importable TSV file. The review screen starts by removing common
low-value items, such as standalone particles and fillers, and lets you put
any item back before importing.

The definitions, readings, pitch/frequency information, and optional media are
generated by *your* Yomitan dictionaries and note format. jpdb supplies the
episode word list; it is not used as the card-definition source.

## Install the extension

1. Unzip the release, if you received a zip file.
2. Open `chrome://extensions` in Chrome and turn on **Developer mode**.
3. Choose **Load unpacked** and select this folder:
   `jpdb-yomitan-anki-extension`.
4. Setup opens automatically. Use **Connect signed-in account** for jpdb and
   follow only the connection rows marked **Action needed**. Checks and
   cleanup settings save automatically.
5. Visit a jpdb anime detail page or one of your jpdb deck pages. The new
   button appears beside an episode or deck.

Chrome keeps the extension while this folder remains in place. To update it,
replace the folder with the new release and press the reload button on
`chrome://extensions`.

## jpdb access

The extension adds an episode to your own jpdb decks using jpdb's existing
page action, then uses jpdb's documented API to read that user deck. A jpdb API
key is required. In setup, **Connect signed-in account** opens the normal jpdb
settings page once. After you click the visible **Use this API key** button on
that page, the extension reads only its labeled API-key row for that one
short-lived connection attempt, verifies the key through the official API,
and stores it in Chrome's local extension storage. The key is only sent to
`jpdb.io`. Manual copy and paste remains available as a fallback. You can
remove the added deck in jpdb when you no longer need it.

Automated access to jpdb vocabulary pages is intentionally not included.
jpdb's [Terms of Use](https://jpdb.io/terms-of-use) prohibit automated access,
including scraping, and say it can result in an immediate automatic ban.

## Enable high-quality Yomitan cards

Card generation needs Yomitan and its local helper running at the same time.
Adding the generated notes directly also needs Anki:

1. **Yomitan**, with the dictionaries and Anki note format you want.
2. The **Yomitan API native helper**, which exposes Yomitan to local tools.
3. For direct import, **Anki Desktop** with the
   [AnkiConnect add-on](https://ankiweb.net/shared/info/2055492159). Anki is not
   required for TSV export.

To install the helper on macOS, double-click
`install-yomitan-api-macos.command` in this folder. The setup page also offers
`yomitan-api-macos-helper.zip`; unzip it first so macOS keeps the command's
executable permission, then double-click the command. It uses no administrator
privileges, downloads one pinned revision of the official helper, verifies its
SHA-256 checksum, and installs the Chrome native-messaging manifest for the
official Yomitan extension. An existing helper manifest is backed up before it
is replaced. If macOS blocks the file because it was downloaded
from the internet, right-click it in Finder, choose **Open**, then choose
**Open** again.

After the installer finishes, it opens Yomitan's **General** settings in
Google Chrome when possible. The remaining Yomitan permission is deliberately
user-controlled:

1. Turn on **Advanced** in Yomitan if it is off.
2. Under **General**, turn on **Enable Yomitan API** and accept Chrome's
   native-messaging permission if prompted.
3. Leave the server URL at `http://127.0.0.1:19633` unless you deliberately
   changed it.
4. Start Anki Desktop. In Anki, confirm that AnkiConnect is installed and
   enabled.

The extension setup checks jpdb, Yomitan, and Anki automatically when it opens
and again when you return from another tab. A manual retry remains available
if a local service takes a few seconds to start. If Yomitan is still not
detected after enabling its API, fully quit and reopen Chrome, then retry.
During import, the review screen lets you choose a Yomitan card format and
destination deck. The selected format controls the Anki model, field
templates, and dictionary-derived content.

## Import flow

1. Click **Add to Anki** for an episode. jpdb adds and opens its deck; click
   the extension's **Continue** button on that deck page. On an existing deck,
   click **Add deck to Anki with Yomitan**.
2. Review the vocabulary. The default filter hides standalone particles and
   low-value vocalizations; each row remains available to re-include. Optional
   filters can ignore bundled JLPT N5/N4 entries or words above frequency-rank
   thresholds of 20k, 30k, or 45k. Frequency ranks are fetched from Yomitan
   only when enabled, for both the spelling and kana reading, using the lower
   rank.
3. Choose a destination deck and a Yomitan card format.
   **Match exact flashcard** is enabled by default and uses Anki's same-note-
   type/first-field check across the entire collection. **Match same word**
   additionally checks expression and reading across all note types and decks.
4. Select one of the outputs:
   - **Add to Anki**: asks Yomitan for each selected word and batches the
     completed notes to AnkiConnect.
   - **Export TSV**: downloads an Anki-importable text file. It cannot package
     downloaded media as an `.apkg`. When Anki is open, the export reads the
     exact model field order. If that order cannot be verified, check the named
     columns in Anki's import preview before completing the import.
   - **Copy for Yomitan**: copies newline-separated terms and opens Yomitan's
     settings so you can use Yomitan's own experimental note generator.

Direct import skips notes that AnkiConnect reports as duplicates. A summary
shows added, skipped, and failed notes so a partial run is visible rather than
silent.

## Speed expectations

The extension gets the jpdb list quickly, but creating a high-quality card
still requires one local Yomitan lookup per selected vocabulary item. A few
hundred items normally means a few minutes with definition-only cards; the
exact time depends on the dictionaries, card template, computer, and whether
audio/media is enabled. Notes are delivered to AnkiConnect in batches, so
Anki itself is not asked to process hundreds of separate requests.

Audio and other media make the run materially slower because Yomitan has to
retrieve and store files. Keep media off for a quick vocabulary import, or use
it only for a smaller reviewed set. You can cancel an in-progress job; notes
already accepted by Anki remain in the target deck.

## Troubleshooting

**“Cannot reach Yomitan API”**

Run the macOS helper installer again, restart Chrome, make sure Yomitan's
**Enable Yomitan API** switch is on, and test it at
`http://127.0.0.1:19633` in Yomitan settings. The helper needs an available
`python3` command.

**“Cannot reach AnkiConnect”**

Open Anki Desktop and verify that the AnkiConnect add-on is enabled. Its usual
local address is `http://127.0.0.1:8765`.

**The cards do not contain the fields I want**

Edit the active card format in Yomitan and make sure the dictionaries you want
are enabled there. This extension intentionally uses Yomitan's templates,
rather than inventing separate definitions or card layouts.

**The extension cannot find the deck**

Confirm that the jpdb API key is valid and that the episode was successfully
added to your jpdb account. Reopen the new jpdb deck page and run the action
there.

## Scope and limitations

The extension is a local personal tool. It uses jpdb's API instead of scraping
the website. It does not export a fully packaged `.apkg`; use direct
AnkiConnect import for media-backed cards or the TSV export for a portable text
import. Dictionary results can differ for homographs, so the review stage is
the place to exclude a surprising result.

The macOS helper installer downloads the official
[Yomitan API helper](https://github.com/yomidevs/yomitan-api) at a pinned
revision and verifies it before installing. Its source and license remain
upstream; this project does not redistribute the helper.
